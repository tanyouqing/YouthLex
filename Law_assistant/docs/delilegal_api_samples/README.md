于适用法律错误，事实认定不清。三、康学健根本不存在因为工作<em>上下班</em>的前提条件在《<em>工伤保险</em>条例》中，交通事故损伤工伤认定的情形条件应为“<em>上下班</em>途中”，这是必须符合的要件。四、原审法院适用和审查法律错误，康学健不符合《<em>工伤保险</em>条例》等法律法规的规定，康学健朝单位反方向行驶的客观行为是否表示为工作<em>上下班</em>行为是本案的关键。被上诉人的抗辩和原审第三人的陈述存在明显的冲突，被上诉人两次做出工伤认定也结果相反。被上诉人作出的工伤认定根本不符合法律依据和程序。一审法院草率作出上班途中的结论也是建立在对事实认定不清且有主观色彩的逻辑错误判断上。被上诉人对工伤的认定和一审法院对于事实和法律的审查均有想当然的主观色彩，另从立法角度考虑，劳动保障法律的立法旨意是保护无恶意劳动者的合法权益，本案康学健负有事故同等责任，可见其当时的客观状态并非是上班行为。\n被上诉人招远市人力资源和社会保障局在法定期间未提交答辩意见。\n原审第三人孙瑞芬、康静伟、刘芬一在法定期间未提交陈述意见。\n各方当事人在一审中提供的证据已随随案电子卷宗移送本院，上述证据在一审庭审中已经质证。经审理，本院同意一审法院判决对证据的认证意见及据此确认的案件事实。\n法院认为\n本院认为，根据《<em>工伤保险</em>条例》第十四条第㈥项之规定，在<em>上下班</em>途中，受到非本人主要责任的交通事故伤害的，应当认定为工伤。《最高人民法院关于审理<em>工伤保险</em>行政案件若干问题的规定》（以下简称若干规定）第六条第㈠、㈢项规定:“对社会保险行政部门认定下列情形为“<em>上下班</em>途中”的，人民法院应予支持:㈠在合理时间内往返于工作地与住所地、经常居住地、单位宿舍的合理路线的<em>上下班</em>途中”。根据《<em>工伤保险</em>条例》第十九条第㈡款的规定，“职工或者其近亲属认为是工伤，用人单位不认为是工伤的，由用人单位承担举证责任”。本案中，根据查明的事实，康学健发生非本人主要责任交通事故是在<em>上下班</em>必经之处，无论其是从居住地到单位，还是从单位到居住地，均需经过康学健涉诉事故发生地点。上诉人在没有证据可以证明康学健是在此路段准备从事其他与工作无关的活动的情况下，就否认康学健不是“<em>上下班</em>途中”，证据不足，其主张本院不予采纳。被上诉人结合调查情况，在上诉人亦未提供康学健当天请假或者他人通知康学健当天无需上班等证据的情况下，作出认定工伤决定并无不当。因此，本院对上诉人请求撤销认定工伤决定的主张不予支持。\n综上所述，上诉人的上诉请求不能成立，应予驳回；一审判决认定事实清楚，适用法律正确，应予维持。依照《中华人民共和国行政诉讼法》第八十九条第一款第㈠项规定，判决如下：\n裁判结果\n驳回上诉，维持原判。\n案件受理费50元，由上诉人温州东大矿建工程有限公司承担。\n本判决为终审判决。\n审判人员\n审判长\t鲁晓辉\n审判员\t杨金勇\n审判员\t纪晓静\n二〇二一年四月六日\n书记员\t闫彩玲\n"
